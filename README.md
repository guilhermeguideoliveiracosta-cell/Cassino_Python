# 🎰 *CAÇA-PYTHON*

**Um jogo simples de caça-níquel desenvolvido em Python para praticar lógica de programação, estruturas condicionais e números aleatórios.**

## 🛠️ *Tecnologias utilizadas*

* **Python 3**
* **Biblioteca random**

## ⚙️ *Funcionalidades*

🎰 **Girar a máquina**

💰 **Escolher o valor da aposta**

⭐️ **Sistema de pontos**

🏆 **Sistema de recorde**

🎯 **Multiplicadores de pontos**

🎉 **Sistema de Jackpot**

📊 **Exibição do último jogo**

## 🎮 *Como jogar*

1. Escolha a opção **JOGAR**.
2. Informe quantos pontos deseja apostar.
3. A máquina irá gerar três linhas com símbolos.
4. Dependendo do resultado, você pode **ganhar ou perder pontos**.
5. Se conseguir três símbolos iguais nas três linhas, você ganha um **JACKPOT**.

Os símbolos utilizados são:

* ⭐️ Estrela
* 🍒 Cereja
* 🥝 Kiwi

## ▶️ Como executar

1. **Instale o Python 3.**
2. **Baixe ou clone este repositório.**
3. Abra o terminal na pasta do projeto.
4. Execute:

```bash
python main.py
```

## 🎯 *Objetivo*

**Projeto desenvolvido para praticar Python, principalmente `if`, `elif`, `else`, `while`, listas, variáveis, entrada de dados e a biblioteca `random`.**
